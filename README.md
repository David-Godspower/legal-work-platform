# Legal Platform Hero Section

A modern, responsive hero section for a legal management platform.

## 🚀 Tech Stack
- **Framework:** Next.js 14+ (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Language:** TypeScript

## ✨ Key Features
- **Responsive Layout:** Adaptive design using Tailwind CSS.
- **Dynamic UI:** Reusable `FloatingCard` component with animation support.
- **SSR-Safe:** Utilizes `next/dynamic` with `ssr: false` to prevent hydration issues with animations.
- **Professional Aesthetics:** Layered background elements for visual depth and refined typography hierarchy.

## 🛠️ Getting Started
1. Clone the repository: `git clone https://github.com/David-Godspower/legal-work-platform.git`
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
